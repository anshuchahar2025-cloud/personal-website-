# Anshu Chahar — Personal Portfolio

## Files
- `index.html` — page content and sections
- `style.css` — layout, colors, responsive design, animations
- `script.js` — mobile navigation, reveal animations, current year, back-to-top

## Run it
1. Extract the ZIP.
2. Open the `anshu_portfolio` folder in VS Code.
3. Open `index.html` in your browser, or use the VS Code Live Server extension.

## Personalize before publishing
1. In `index.html`, replace `your.email@example.com` with your real email address.
2. Add your GitHub and LinkedIn links if you want them shown.
3. Update the skill list to match what you can confidently demonstrate.
4. Update project status and descriptions as each project becomes functional.
5. If you want a real portrait, replace the letter avatar in the hero card with an image element and style it in `style.css`.

The site is a static portfolio; the contact button opens the visitor's email app. It does not currently include a backend or contact-form database.
